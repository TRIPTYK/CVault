# References pour CV Manager MVP

## Source principale

### Editeur Europass officiel de l'UE

- **URL** : https://europa.eu/europass/fr/create-europass-cv
- **Pertinence** : Reference majeure pour le modele de donnees, la structure du formulaire et le format d'export Europass
- **Elements cles a reprendre** :
  - Structure du formulaire avec sections depliables
  - Layout split-panel (formulaire a gauche, apercu a droite)
  - Modele de donnees complet (infos personnelles, profil, formation, experience, langues CECRL, competences numeriques)
  - Grille de niveaux de langue CECRL (A1-C2) avec decomposition comprehension/expression
  - Indicateurs visuels de niveau de competence (points/barres)
  - Format de rendu PDF Europass (en-tetes bleus, photo a gauche, mise en page standardisee)

## Grille CECRL (Cadre Europeen Commun de Reference pour les Langues)

- **URL** : https://www.coe.int/fr/web/common-european-framework-reference-languages/level-descriptions
- **Pertinence** : Standard europeen pour les niveaux de langue. Utilise dans le modele Europass.
- **Niveaux** :
  - A1 : Utilisateur elementaire (decouverte)
  - A2 : Utilisateur elementaire (survie)
  - B1 : Utilisateur independant (seuil)
  - B2 : Utilisateur independant (avance)
  - C1 : Utilisateur experimente (autonome)
  - C2 : Utilisateur experimente (maitrise)
- **Decomposition par competence** :
  - Comprehension orale (ecouter)
  - Comprehension ecrite (lire)
  - Expression orale en interaction (prendre part a une conversation)
  - Expression orale en continu (s'exprimer oralement en continu)
  - Expression ecrite (ecrire)

## Formats de CV professionnels

### Format Classique

- **Inspiration** : Formats courants utilises en France pour les reponses aux appels d'offres
- **Caracteristiques** :
  - Mise en page epuree, professionnelle
  - En-tete avec nom, titre et coordonnees
  - Sections clairement delimitees
  - Pas de contrainte de format impose (adaptable a la charte de l'entreprise)
  - Couleurs et polices personnalisables
